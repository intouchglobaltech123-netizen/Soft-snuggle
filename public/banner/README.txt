Background-free cut-outs of the garments, used by the shop banner.

Named after the product slug, so public/banner/<slug>.webp belongs to the
product with that slug and the banner picks it up with no code change. A
product without a file here simply does not appear in the banner.

These were cut from public/products/<slug>/1-front.webp. Cutting a white
garment off a cream linen backdrop is not always reliable: zebra-jabla came
back with only its printed motif and no garment, so it has no file here.
Check any new cut-out before adding it.
